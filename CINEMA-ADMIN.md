# Киноужины: администрирование и запуск

Кабинет: /kino/admin. Использует ключ CINEMA_ADMIN_SECRET (случайный секрет минимум 32 символа); вход не хранится в браузере. Для production обязательна DATABASE_URL PostgreSQL. Нельзя использовать тестовый ключ локального предпросмотра на сервере.

Редактор меняет фильм, дату, время, цену, описания, меню, фото; можно создать новый вечер. Фото перекодируются в WebP и хранятся в БД. Настройки вечеров сохраняются в cinema_event_overrides и не теряются при перезапуске/сборке. ID и slug существующего вечера стабильны. Цены ранее созданных заказов не меняются при изменении афиши. При изменении даты уже проданного вечера нужно отдельно связаться с гостями.

Для телефонной брони выбрать места, имя, телефон, сохранить. Статус reserved, публичные места sold (занято), оплата НЕ получена. Отмена reserved освобождает места. Отметка оплаты требует описания подтверждения; сохраняется запись cinema_admin_audit. Оплаченный заказ не отменяется кнопкой телефонной брони: требуется отдельная процедура возврата.

Публичная схема опрашивает БД каждые 5 секунд, проверка занятости на сервере атомарная. Время обновления видимого состояния до 5 секунд. Гости сейчас бронируют по телефону, онлайн-продажи закрыты.

## Цены столов

В редакторе афиши поля «Стоимость мест за каждым столом» задают цену за одного гостя за конкретным столом; пустое поле использует базовую цену. Цена одинакова для двух мест одного стола. Кнопка «Применить базовую цену ко всем столам» очищает индивидуальные цены. Для применения нажать «Сохранить афишу». Пока цены не сохранены, создание телефонной брони заблокировано, схема показывает сохранённые значения.

В заказах сохраняются сумма и цены отдельных мест (cinema_order_prices). Изменение афиши не пересчитывает существующие заказы. Старые заказы с общей единой ценой продолжают работать. Сервер проверяет ожидаемую сумму и отклоняет бронирование, если цены изменились после выбора. Публичная схема обновляет цены вместе с состояниями мест.

## Выбор мест гостями и нумерация

До подключения ЮKassa гости могут выбрать свободные места и увидеть цены/итог, но такой выбор не создаёт резерв в базе. Для подтверждения предусмотрена кнопка звонка администратору. Клик по столу выбирает его свободные места, клик по месту — только его; занятые места недоступны. Публичные формы оплаты открываются только при включённых продажах.

Видимые номера столов идут по координатам сверху вниз, в пределах ряда слева направо. Внутренние идентификаторы столов и мест сохранены, поэтому имеющиеся цены и брони продолжают относиться к тем же физическим позициям.
